# My Patient Hub — Afghanistan Edition

A React + Vite healthcare portal concept with a glassmorphism interface and a patient-dashboard layout.

## Dashboard layout
- Patient portal heading and doctor/hospital search
- Summary cards for appointments, doctor listings, facilities, and care tools
- Quick access to doctors, appointments, hospitals, services, and medical equipment
- Appointment request summary and featured doctor cards
- Afghanistan-focused sample cities and AFN equipment pricing

## Included features
- React components separated by section
- Sidebar navigation (no top navigation bar)
- Light/dark appearance toggle
- Hamburger (three-line) button collapses/expands the shared dashboard sidebar on every page
- Navigation remains available across the doctor, hospital, service, marketplace, appointment, and contact pages
- Care Network Snapshot bar visualization for a polished presentation highlight
- Sample sign-in/sign-up flow for demonstration
- Doctor directory with city/specialty filters and illustrative OpenStreetMap pins
- Appointment request demo flow
- Medical equipment marketplace and basket
- Responsive layouts for desktop and mobile

## Technology highlights
- **React 18** for reusable, component-based pages and interactive UI state
- **Vite 6** for a fast local development server and production build workflow
- **Lucide React** for consistent, accessible-style healthcare and navigation icons
- **Custom CSS** for glassmorphism, responsive layouts, dark/light themes, and the care-network visualization

## Run locally
1. Install Node.js LTS if it is not already installed.
2. Extract this ZIP and open the `MyPatientHub-Afghanistan-Completed` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Demo notice
This is a frontend demonstration. Doctor profiles, clinic locations, hospital listings, prices, and appointments are sample data and are not verified live healthcare services. The map pins are illustrative; confirm real clinic details independently. The sign-in flow is local demo behavior, not production authentication or secure server storage.
